#  TechInside

Uma aplicação web desenvolvida com HTML, CSS e JavaScript, criada para apresentar serviços de tecnologia da informação, suporte técnico, cloud, segurança, redes, governança e desenvolvimento de TI.

##  Demonstração

 [Clique aqui para acessar o TechInside](https://caique-torres.github.io/Tech-Inside/)

##  Funcionalidades

- Apresentação da empresa  
- Apresentação dos serviços de TI  
- Suporte Técnico  
- Cloud Gerenciado  
- Segurança de TI  
- Redes  
- Governança de TI  
- Desenvolvimento de TI  
- Formulário de contato  
- Interface responsiva
- Menu lateral de navegação  

##  Tecnologias utilizadas

HTML5  
CSS3  
JavaScript  

##  Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, organização de conteúdo, responsividade, navegação entre seções, formulários e manipulação do DOM.
